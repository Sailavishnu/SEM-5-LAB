1) 1D PARITY  (Program now ASKS which scheme to use: Even or Odd)
   Flow: data_to_send = msg(m) + parity(p)
   EVEN scheme -> total 1's (data+parity) must be EVEN  for No Error
   ODD  scheme -> total 1's (data+parity) must be ODD   for No Error
   All 4 combinations covered below (input = "Hi", 0100100001101001,
   which has 6 ones -> already even).
----------------------------------------------------------------

TEST 1.1 : EVEN parity | No error
  Message (m)          : 0100100001101001   (6 ones -> already even)
  Parity bit (p)       : 0   (kept even)
  Data sent (m+p)      : 01001000011010010
  Received (no flip)   : 01001000011010010  -> total 1's = 6 (even)
  ANSWER                : NO ERROR DETECTED -> Recovered: "Hi"

TEST 1.2 : EVEN parity | Error at bit position 0
  Data sent            : 01001000011010010
  Received (bit0 flip) : 11001000011010010  -> total 1's = 7 (odd)
  ANSWER                : ERROR DETECTED   (odd count breaks even scheme)

TEST 1.3 : ODD parity | No error
  Message (m)          : 0100100001101001   (6 ones -> already even, need odd)
  Parity bit (p)       : 1   (forces total to odd)
  Data sent (m+p)      : 01001000011010011
  Received (no flip)   : 01001000011010011  -> total 1's = 7 (odd)
  ANSWER                : NO ERROR DETECTED -> Recovered: "Hi"

TEST 1.4 : ODD parity | Error at bit position 0
  Data sent            : 01001000011010011
  Received (bit0 flip) : 11001000011010011  -> total 1's = 8 (even)
  ANSWER                : ERROR DETECTED   (even count breaks odd scheme)

3) CRC  (Generator G(x) = 1001 i.e. x^3+1, default if "0" entered)
   Flow: dividend = data + (r zeros), r = len(G)-1
         CRC = remainder of dividend / G  (mod-2 XOR division)
         Transmitted = data + CRC
   Receiver: divide received / G -> remainder = 0 means No Error
----------------------------------------------------------------

TEST 3.1 : Input = "Hi" | Generator = 1001 | No error
  Source data (D)      : 0100100001101001
  D padded with 3 zeros: 0100100001101001000
  CRC remainder        : 101
  Transmitted (D+CRC)  : 0100100001101001101
  Received (no flip)   : 0100100001101001101
  Remainder on receive : 000
  ANSWER                : NO ERROR DETECTED -> Recovered: "Hi"

TEST 3.2 : Input = "Hi" | Generator = 1001 | Error at bit position 1
  Transmitted          : 0100100001101001101
  Received (bit1 flip) : 0000100001101001101
  Remainder on receive : 100
  ANSWER                : ERROR DETECTED

TEST 3.3 : Input = "A" | Generator = 1001 | No error
  Source data (D)      : 01000001
  D padded with 3 zeros: 01000001000
  CRC remainder        : 000
  Transmitted (D+CRC)  : 01000001000
  Received (no flip)   : 01000001000
  Remainder on receive : 000
  ANSWER                : NO ERROR DETECTED -> Recovered: "A"

TEST 3.4 : Input = "A" | Generator = 1001 | Error at bit position 4
  Transmitted          : 01000001000
  Received (bit4 flip) : 01001001000
  Remainder on receive : 001
  ANSWER                : ERROR DETECTED

4) CHECKSUM  (Block size n=8 default, 1's complement addition
   with end-around carry; checksum = complement of block-sum)
   Receiver: sum all blocks incl. checksum, complement -> 0 = No Error
----------------------------------------------------------------

  Data (padded)        : 0100100001101001

  Block 2              : 01101001
